# TaskFlow — Protótipo (FUMEC)

Integrantes: Lucas Bastos e Giovana Azevedo. Disciplina: Desenvolvimento Web Front-End.

## Entregáveis
- `01_Relatorio_TaskFlow.pdf`: relatório com descrição e capturas das 7 telas.
- `02_Prototipo_TaskFlow.pdf`: protótipo visual com 7 telas.
- `Kanban_TaskFlow.xlsx`: planejamento das atividades da dupla.
- `prototipo_navegavel.html`: protótipo HTML navegável; abrir em navegador. **Demonstração sem backend ou persistência de dados.**

## Git / GitHub
Criar/reutilizar o repositório GitHub do TaskFlow, adicionar os arquivos, usar branches `main`, `develop` e `feature/...` quando apropriado e commits semânticos atômicos. O material não foi publicado automaticamente no GitHub.

## Observações
Os dados e os números das telas são ilustrativos. Este trabalho representa uma etapa de prototipação, não um sistema em produção.
